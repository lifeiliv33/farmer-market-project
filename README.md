# Проект: Магазин фермерских продуктов «У дома»

## О проекте
Мы закупаем молоко, яйца, овощи и сыры у местных хозяйств и продаём их жителям района. Наш бизнес строится на свежести товара, удобном расположении и постоянных клиентах, которые ходят к нам каждую неделю.
