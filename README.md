# Автоматизация бизнес-процессов магазина фермерских продуктов «у дома»

## 📌 Описание проекта
Информационная система для розничного магазина фермерских продуктов. Система предназначена для автоматизации учёта поставщиков (местных хозяйств), товаров, закупок, продаж, остатков на складе, клиентов и программы лояльности. 

Проект включает в себя:
- Базу данных (MS SQL Server).
- Десктопное приложение (C# WPF, шаблон MVVM).
- Полный комплект проектной документации.

## 👥 Команда проекта
- **Разработчик 1** (Архитектор/БД): Аналитика, проектирование БД, слой доступа к данным, модуль авторизации, документация.
- **Разработчик 2** (Backend/Логика): ER-диаграмма, seed-скрипты, модули «Товары», «Поставщики», «Закупки», «Склад».
- **Разработчик 3** (Frontend/UI): Макет в Figma, вёрстка интерфейса, модули «Продажи», «Клиенты», «Лояльность», «Отчёты».

## 🛠 Стек технологий
- **Язык:** C# (.NET 6/7/8)
- **Интерфейс:** WPF (Windows Presentation Foundation)
- **Архитектура:** MVVM
- **База данных:** MS SQL Server
- **Доступ к данным:** Entity Framework (или ADO.NET)
- **Инструменты:** Visual Studio, Figma, draw.io

## 📂 Структура репозитория
- `01_Docs/` — вся проектная документация (требования, бизнес-процессы, финансы, поставщики).
- `02_Database/` — SQL-скрипты создания БД, резервные копии (.bak).
- `03_SourceCode/` — исходный код WPF-приложения.
- `04_Presentation/` — презентация проекта (PowerPoint).

## 🚀 Инструкция по развертыванию (будет дополнено на Этапе 4)
1. Развернуть базу данных из скрипта `02_Database/database_creation.sql`.
2. Открыть решение в Visual Studio.
3. Проверить строку подключения в `App.config`.
4. Запустить приложение (F5).
