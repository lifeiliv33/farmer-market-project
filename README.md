# Автоматизация бизнес-процессов магазина фермерских продуктов «у дома»

## Описание проекта
Информационная система для учёта поставщиков, товаров, закупок, продаж, остатков на складе, клиентов и программы лояльности. Состоит из базы данных (MS SQL Server) и десктопного приложения (C# WPF).

## Стек технологий
- **Язык программирования:** C# (.NET)
- **Интерфейс:** WPF (Windows Presentation Foundation), шаблон MVVM
- **База данных:** MS SQL Server
- **ORM:** Entity Framework (или ADO.NET)
- **Среда разработки:** Visual Studio 2022

## Команда проекта
- **Разработчик 1:** Архитектура, БД, модуль авторизации, README
- **Разработчик 2:** Модули Товары, Поставщики, Закупки, Склад
- **Разработчик 3:** Модули Продажи, Клиенты, Лояльность, Сотрудники, Отчёты, UI/UX

## Инструкция по развёртыванию

### 1. Развертывание базы данных
1. Откройте **SQL Server Management Studio (SSMS)**.
2. Выполните скрипт `database_creation.sql` (находится в корне репозитория) для создания базы данных и таблиц.
3. (Опционально) Восстановите базу из резервной копии `FarmerMarketDB.bak`.

### 2. Запуск приложения
1. Откройте решение `.sln` в **Visual Studio**.
2. Проверьте строку подключения в файле `App.config`. Она должна указывать на вашу локальную базу данных.
3. Соберите решение (Build -> Build Solution).
4. Запустите приложение (F5).
