# Описание бизнес-процессов

## 1. Закупка у фермеров
1. Товаровед формирует заявку поставщику на основе остатков на складе.
2. Поставщик привозит товар.
3. Товаровед принимает товар, создает документ «Закупка» (указывает дату, поставщика, позиции с количеством и закупочной ценой).
4. При подтверждении приемки система автоматически увеличивает остатки на складе.

## 2. Розничная продажа
1. Продавец открывает модуль «Продажи».
2. Добавляет товары в чек (сканирует штрихкод или выбирает из списка).
3. Система рассчитывает итоговую сумму и наценку.
4. Если у клиента есть карта лояльности, система применяет скидку или списывает баллы.
5. Продавец выбирает способ оплаты (наличные/карта), чек закрывается, остатки на складе уменьшаются.

## 3. Программа лояльности
1. Клиент совершает покупку.
2. Система автоматически начисляет баллы на его карту (например, 5% от суммы).
3. Баллы можно списать при следующей покупке (частично или полностью).
4. Все операции фиксируются в истории карты.

## 4. Списание товаров
1. Товаровед проводит инвентаризацию.
2. Выявляет просрочку или брак.
3. Создает документ «Списание» с указанием причины (просрочка, бой) и ответственного сотрудника.
4. Остатки на складе уменьшаются.
