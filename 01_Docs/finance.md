# Финансовая модель магазина

## Основные показатели
- **Средняя наценка:** 30% (зависит от категории товара).
- **Целевая аудитория:** жители района, покупающие свежие продукты еженедельно.

## Примерный расчет на 1 неделю
| Показатель | Значение |
|---|---|
| Количество постоянных клиентов | 50 человек |
| Средний чек одной покупки | 800 руб. |
| Количество покупок в неделю | 1,5 на человека |
| **Выручка в неделю** | **60 000 руб.** |
| Закупка товара (себестоимость) | ~46 000 руб. |
| **Валовая прибыль в неделю** | **~14 000 руб.** |

*Примечание: в приложении модуль «Отчёты» будет автоматически рассчитывать эти показатели на основе реальных данных из БД.*
