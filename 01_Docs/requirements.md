# Требования к системе (Функциональные модули)

Согласно ТЗ, приложение должно включать 9 основных модулей:

1. **Товары:** CRUD (создание, чтение, обновление, удаление), поля: наименование, категория, ед. изм., цены (закуп/продажа), остаток, статус. Поиск по названию и категории.
2. **Поставщики:** Учет фермерских хозяйств (название, контакты, адрес, категории товаров).
3. **Закупки:** Фиксация поставок, состав позиций, итоговая сумма. Автоматическое увеличение остатков на складе при приемке.
4. **Продажи:** Оформление розничной продажи, быстрый поток, расчет скидок и баллов.
5. **Клиенты:** База постоянных покупателей, история покупок.
6. **Программа лояльности:** Начисление/списание баллов, история операций по карте.
7. **Склад и остатки:** Учет остатков, оповещение о минимальном пороге, акты списания (просрочка, брак).
8. **Сотрудники:** Данные о продавцах, товароведах, менеджерах (роли, статус).
9. **Отчёты:** Выручка, прибыль, продажи по категориям, доля постоянных клиентов, наценка.

**Нефункциональные требования:**
- Валидация ввода (цены, телефоны).
- Роли доступа: Администратор, Товаровед, Продавец.
- Русскоязычный интерфейс.
